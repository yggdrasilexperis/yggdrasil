# Yggdrasil.Infrastructure

Everything that talks to the outside world: Postgres through EF Core, ASP.NET Core
Identity and JWT signing.

```
Persistence/     DbContext, one EF config per entity, and the demo data seeder
Migrations/      generated by dotnet ef
Repositories/    implementations of Application's repository interfaces
Identity/        ApplicationUser, sign-up and login, JWT tokens
DependencyInjection.cs   AddInfrastructure(), wires all of it up
```

Deleting a quiz deletes its questions and comments, and deleting a question deletes
its answer options. A user can't be deleted while they still own quizzes or
comments.
